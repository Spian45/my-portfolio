# My Personal Links Hub 🚀

A lightweight, single-file landing page for all my social media, gaming, and project links. 

## 📖 Description

This repository contains the static website I use for my personal link-in-bio page. It's built specifically for my own use to route visitors to my various platforms (so it's just my personal one, not a template for everyone else, hehe). 

Since it uses only standard HTML and CSS with no external frameworks, it is extremely fast to load, highly secure, and easy for me to update whenever I need to add a new link.

## ✨ Features

* **Single-File Architecture:** Everything (HTML structure and CSS styling) is contained within `index.html`.
* **Modern Dark Theme:** A sleek, low-contrast dark mode design.
* **Fully Responsive:** Adapts seamlessly to mobile screens, tablets, and desktop monitors.
* **Hover Animations:** Smooth transitions and shadow effects on the link buttons.
* **Zero Dependencies:** No npm, Node.js, or heavy frameworks required.
